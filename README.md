# Status Monitor

Eine Android-App zur Anzeige von detaillierten System- und Geräteinformationen.

## Features

### 🔋 Akku
- Ladestand (%)
- Status (geladen, lädt, entlädt, ...)
- Stromquelle (USB, Wireless, Batterie)
- Zustand (gut, schwach, tot, ...)
- Temperatur
- Spannung
- Technologie (Li-Ion, Li-Po, ...)
- Strom aktuell (Ampere)
- Restladung (mAh)
- Ladezyklen
- Akku-Gesundheit *(nur mit Root)*

### 💾 Speicher
- Gesamt
- Belegt
- Frei

### 🧠 RAM
- Gesamt
- Belegt
- Verfügbar
- Warnung bei wenig freiem Speicher

### ⚙️ Chip / Prozessor
- SoC-Hersteller
- SoC-Modell
- Hardware
- Board
- Anzahl Kerne
- Architektur (ARM64, ...)
- Takt pro Kern *(max. in Klammern)*

### 📱 Gerät
- Hersteller
- Modell
- Android-Version
- Sicherheits-Patch-Level
- Display-Auflösung
- Pixeldichte (dpi)
- Bildwiederholrate (Hz)
- Laufzeit seit Start (Uptime)

## Installation

1. Die `app-release.apk` aus dem Repository herunterladen
2. Auf dem Handy **"Unbekannte Quellen erlauben"** aktivieren
3. APK öffnen und installieren
